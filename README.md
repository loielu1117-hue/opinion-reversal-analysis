# 基于情感分析与主题建模的舆情反转事件演化机制研究

> **项目V1.0**：舆情反转事件中公众情感极化的算法煽动机制实证分析  
> **案例**："胖猫"事件（2024）& "李明德"事件（2025）  
> **作者**：刘颖 | **指导老师**：金玲玲 副教授（海南师范大学）

---

## 📌 项目背景

社交媒体时代，舆情反转事件频发，公众情感极化日益突出。现有研究多将推荐算法视为"黑箱"，缺少对算法逻辑与情感演化之间动态关系的量化建模。

本项目以"胖猫"（2024.05.19反转）和"李明德"（2025.02.13反转）两起典型事件为样本，通过**情感分析 + 主题建模**构建"情感-主题"二维分析框架，实证检验以下两个核心假设：

- **H1（情感优先筛选）**：情绪强度越高的内容，获得的互动量（点赞+评论）越高，算法倾向于优先推荐情绪化内容。
- **H2（信息茧房固化）**：反转发生后，不同情感立场的群体关注的话题显著分化，形成"同场不同证据链"的茧房效应。

## 📊 数据采集

| 事件 | 平台 | 回答数 | 时间跨度 | 反转节点 |
|------|------|--------|----------|----------|
| 胖猫事件 | 知乎 | 924条 | 2024.04.01 - 2024.12.31 | 2024.05.19（警方通报） |
| 李明德事件 | 知乎 | 510条 | 2025.01.01 - 2025.12.31 | 2025.02.13（砸车曝光） |

- **采集方式**：Python爬虫（`requests` + `BeautifulSoup`），提取字段包括：回答正文、发布时间、作者昵称、点赞数、评论数。
- **数据清洗**：剔除匿名/注销用户、HTML标签、表情符号、URL链接，过滤长度<10字的短文本。
- **分词工具**：`jieba` + 自定义领域词典（156个专有名词，如"胖猫""谭竹""PUA"）。

---

## 🛠️ 方法论流程

### 1. 情感分析（Sentiment Analysis）

- **基础模型**：`SnowNLP`（贝叶斯分类器）
- **模型微调**：人工标注500条事件相关评论（正/负各250条），重新训练模型
- **优化效果**：准确率从 **68.6%** 提升至 **80.1%**
- **输出指标**：
  - 情感均值（$\bar{S_t}$）：反映舆论整体倾向
  - 情感标准差（$\sigma_t$）：作为**极化指数**，衡量意见分歧程度

### 2. 主题建模（Topic Modeling）

- **模型**：`gensim` 的 LDA（Latent Dirichlet Allocation）
- **主题数确定**：困惑度（Perplexity）+ 一致性（Coherence Score），最终选定 **K=5**
- **分段处理**：将每个事件分为 **反转前 / 反转窗口 / 反转后** 三个阶段，分别提取主题
- **茧房量化**：计算不同情感倾向群体（同情派 vs 批评派）高频词的 **Jaccard 相似系数**，值越低表示话题隔离越严重

### 3. 统计分析

- **相关性检验**：计算每条回答的"情感强度（|得分-0.5|）"与"互动量（点赞+评论）"之间的皮尔逊相关系数（$r$）

---

## 📈 核心发现（V1.0 结论）

| 维度 | 胖猫事件 | 李明德事件 | 统计显著性 |
|------|----------|------------|------------|
| 情感-互动相关性 | $r = 0.42$ | $r = 0.39$ | $p < 0.01$，显著正相关 |
| 反转窗口极化峰值 | $\sigma = 0.42$ | $\sigma = 0.418$（次日跳升） | 反转触发情感撕裂 |
| 反转前后主题相似度 | Jaccard < 0.1 | Jaccard < 0.1 | 话题从"个人叙事"转向"事实认定" |
| 反转后阵营话题隔离度 | Jaccard ≈ 0.13 | Jaccard ≈ 0.14 | 不同立场群体"各说各话"，茧房效应明显 |

> **结论**：平台算法优先推送强情绪内容，导致阵营边界硬化；反转后信息供给向各自主张收缩，茧房通过"同场不同证据链"逐步定型。这即为论文所称的 **"算法煽动机制"**。

## 🚀 快速开始

### 环境配置

```bash
# 克隆仓库
git clone https://github.com/loielu1117-hue/opinion-reversal-analysis.git
# 安装依赖
pip install -r requirements.txt
```
### 运行顺序

```bash
cd src

# 1. 爬取数据（需配置Cookie/Headers）
python 1_spider.py

# 2. 预处理
python 2_preprocess.py

# 3. 情感分析（含模型训练）
python 3_sentiment.py

# 4. 主题建模
python 4_topic_modeling.py

# 5. 生成可视化图表
python 5_visualization.py

# 6. 统计检验
python 6_stat_analysis.py
```
注意：由于知乎反爬策略，1_spider.py 可能需要更新 Cookie 或使用离线数据。已将清洗后的CSV文件存放于 data/processed/ 下，可跳过爬虫步骤直接运行后续脚本。

## 🔮 下一步规划（V2.0 升级方向）

当前版本（V1.0）已完成 "事后归因分析"。后续将升级为 "舆情反转节点预测系统"：

产出：输出风险评分 + 关键驱动因子（SHAP可解释性分析），供舆情监管部门提前介入。
